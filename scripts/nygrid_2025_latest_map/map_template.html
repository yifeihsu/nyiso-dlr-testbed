Model and map conventions

Zone labels identify the model's accounting groups. They are schematic anchors, not official boundary polygons. Connections show model adjacency, not surveyed line routes.

Retained AC couplings represent eliminated passive buses. Detailed corridors show the original parent records and their recovered branch identities.

Interface membership is the model's frozen diagnostic definition. Complete physical NYISO meter membership is unverified. Arrows follow the declared positive member orientation; negative totals reverse them.

Model MW uses the synthetic 100-MVA electrical base. Public scale divides aggregate power by γ = 0.30012075175285535. Recovered amperes are never rescaled by γ.

Equation/accounting qualification, operating limits and conductor eligibility are separate. No annual solution was rerun to create this map.
